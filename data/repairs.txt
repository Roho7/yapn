# Self-corrections, unmarked lists, and no-change controls for the LLM cleanup pass.
# One utterance per line: spoken ||| expected. "\n" in the expected text is a line break.
# The spoken side is synthesised with `say` by scripts/make-repair-clips.sh into data/repair-clips/.
# Backticked text in the expected side is a dev token, as in prompts.txt. Numbers are written the way
# Parakeet writes them ("4 o'clock"), since cleanup must not respell them.
# A control has the same text on both sides: cleanup must leave it alone.
